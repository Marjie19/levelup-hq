# Roadmap

## Phase 1: MVP ✅
- Journey map: terms → graduation → life goals, with GPA per term, XP, levels and Dean's List badges
- Side quests: certs, hackathons, projects and orgs, each worth XP
- Money: monthly budget, expenses by category, wishlist with savings progress
- Setup and Settings: name, years, terms per year, age, Dean's List cutoff

## Phase 1.5: Clean up and organize (NEXT)
- Reorganize the layout so it feels less cluttered: a clearer home screen and better grouping
- Better navigation on iPhone (bottom tab bar?)
- Make it installable on the iPhone home screen (PWA: manifest and icons)

## Phase 2: Receipt scanning
- Snap a receipt photo → AI reads the total, store and category → auto-adds the expense
- Needs a small backend to keep the AI API key secret (never put keys in the frontend)

## Phase 3: Planner + sync
- Tasks, deadlines and class schedule (tasks and schedule combined)
- Google Calendar sync
- Login and cloud database so laptop and iPhone share the same data (e.g. Supabase or Firebase)

## Phase 4: Share it
- Deploy online (Vercel or Netlify) and let classmates use it
- Interview 5 classmates, collect feedback, track usage (PM portfolio story)
